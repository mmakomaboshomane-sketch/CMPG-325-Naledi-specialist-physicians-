# Milestone 2 – CCTV Implementation

**Client:** Naledi Specialist Physicians  
**Client ID:** CLI-006  
**Project Code:** CMPG325-2026-006

## Implementation

Four CCTV cameras were included in the network design.

A dedicated VLAN was created to separate CCTV traffic from other departments.

**VLAN 50 – CCTV**

## Verification

The following command was used to check the CCTV VLAN:

`show vlan id 50`

The output was checked to verify the CCTV port assignments.

## Result

The CCTV implementation provides a dedicated VLAN for the cameras, separating CCTV traffic from the other departmental VLANs.
