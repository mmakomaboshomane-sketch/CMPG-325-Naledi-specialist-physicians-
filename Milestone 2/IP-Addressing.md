# Milestone 2 – IP Addressing

**Client:** Naledi Specialist Physicians  
**Project Code:** CMPG325-2026-006

## Network Addressing

The network uses the address block 10.12.0.0/16.

The network is divided into VLANs to separate departments and services.

| VLAN ID | Department/Service |
|---|---|
| 10 | Administration |
| 20 | Doctors |
| 30 | Reception |
| 40 | Records |
| 50 | CCTV |
| 99 | Management |

Each VLAN provides separation between departments and services. Trunk links carry VLAN traffic between the switches.
