
Client Requirements

Naledi Specialist Physicians requires a reliable and structured computer network that:
•	Provides reliable connectivity between users, network devices and required services.
•	Separates departments and network services using VLANs.
•	Protects confidential customer/medical records through appropriate network segmentation and access controls.
•	Provides reliable access to applications such as medical records, appointment scheduling, billing and office applications.
•	Provides Internet connectivity to relevant users.
•	Provides a dedicated network for CCTV traffic.
•	Accommodates the four CCTV cameras introduced through CR7.
•	Implements Spanning Tree Protocol (STP) to prevent Layer 2 switching loops.
•	Includes an appropriate STP root bridge design.
•	Provides a dedicated management network for network administration.
•	Uses the assigned 10.12.0.0/16 IP addressing block.
•	Provides sufficient capacity for future users, devices and departments.
•	Allows successful end-to-end connectivity testing in Cisco Packet Tracer.
